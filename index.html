Вопросы

Частые вопросы

Это безопасно?

Установщик не запрашивает лишних прав и не устанавливает ничего, кроме самого лаунчера. Если антивирус или SmartScreen предупреждают о неизвестном разработчике — это нормально для несертифицированных .exe, файл всё равно можно запустить через «Подробнее → Выполнить в любом случае».

Нужно ли ставить Java отдельно?

Нет, лаунчер сам скачивает нужную версию Java Runtime при первой установке версии Minecraft.

Работает ли с лицензионным аккаунтом Microsoft?

Текущая версия рассчитана на офлайн-профили (ник без пароля). Поддержка входа через Microsoft — в планах на следующую версию.

Можно ли перенести моды из другого лаунчера?

Да — скопируй папку mods в директорию профиля Uran Launcher, лаунчер подхватит содержимое при следующем запуске.

Uran Launcher — independent-проект, не связан с Mojang Studios, Microsoft или Minecraft напрямую. Minecraft — товарный знак Mojang Studios.
