Вопросы

Частые вопросы

Почему Windows показывает предупреждение при установке?

Установщик пока не подписан сертификатом — из-за этого SmartScreen может показать предупреждение о неизвестном издателе. Это ожидаемо для новых independent-программ и мы работаем над получением сертификата. Если вы не уверены в источнике файла, не запускайте его.

Нужно ли ставить Java отдельно?

Нет, лаунчер сам скачивает нужную версию Java Runtime при первой установке версии Minecraft.

Работает ли с лицензионным аккаунтом Microsoft?

Текущая версия рассчитана на офлайн-профили (локальный ник без входа в аккаунт). Поддержка входа через лицензионный аккаунт Microsoft — в планах на следующую версию.

Можно ли перенести моды из другого лаунчера?

Да — скопируй папку mods в директорию профиля Uran Launcher, лаунчер подхватит содержимое при следующем запуске.

Uran Launcher — independent-проект, не связан с Mojang Studios, Microsoft или Minecraft напрямую. Minecraft — товарный знак Mojang Studios.
